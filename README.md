# 智能任务管理系统

基于 Node.js + React + Supabase 的全栈任务管理应用。

## 功能

- 输入任务标题 + 选择优先级（高/中/低）添加任务
- 任务列表按创建时间倒序显示
- 每条任务显示标题、优先级标签、完成状态
- 切换完成/未完成、删除任务
- 已完成任务自动加删除线、颜色变淡
- 按优先级筛选（全部/高/中/低）
- 数据存储在 Supabase 云端数据库

## 技术栈

- **后端**: Node.js + Express
- **前端**: React (CDN 引入)
- **数据库**: Supabase (PostgreSQL)
- **部署**: Vercel

## 本地开发

1. 安装依赖：`npm install`
2. 复制环境变量：`cp .env.example .env` 并填写 Supabase 凭据
3. 启动服务：`npm start`
4. 打开 http://localhost:3000

## Supabase 建表 SQL

```sql
create table if not exists tasks (
  id bigint generated by default as identity primary key,
  title text not null,
  priority text not null default '中' check (priority in ('高', '中', '低')),
  completed boolean not null default false,
  created_at timestamptz not null default now()
);

alter table tasks enable row level security;
create policy "Allow anon read" on tasks for select using (true);
create policy "Allow anon insert" on tasks for insert with check (true);
create policy "Allow anon update" on tasks for update using (true) with check (true);
create policy "Allow anon delete" on tasks for delete using (true);
```

## 环境变量

| 变量名 | 说明 |
|--------|------|
| SUPABASE_URL | Supabase 项目 URL |
| SUPABASE_ANON_KEY | Supabase Publishable Key |
