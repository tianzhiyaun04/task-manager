# 智能任务管理系统

Node.js（后端）+ React（前端）+ Supabase（PostgreSQL 云端数据库），可直接部署到 Vercel。

## 功能

- 输入任务标题 + 优先级（高 / 中 / 低）添加任务
- 任务列表按创建时间倒序显示
- 每条任务显示标题、优先级标签、创建时间、完成状态
- 每条任务支持「标记完成 / 标记未完成」与「删除」
- 已完成为删除线 + 颜色变淡
- 按优先级筛选（全部 / 高 / 中 / 低）
- 数据存 Supabase，关闭浏览器再打开依然存在

## 目录结构

```
task-manager/
├── api/tasks.js        # Vercel Serverless Function（/api/tasks）
├── lib/supabase.js     # Supabase 客户端（读取环境变量）
├── lib/tasks.js        # 业务逻辑：列表 / 新增 / 切换完成 / 删除
├── server/index.js     # 本地运行用的 Express 服务（同时托管前端构建产物）
├── src/                # React 前端（Vite）
├── .env.example        # 环境变量模板（真实 .env 不要提交）
└── .gitignore          # 已忽略 .env / node_modules / dist
```

## 本地运行

```bash
npm install
copy .env.example .env    # 填入 SUPABASE_URL 与 SUPABASE_ANON_KEY
npm run local             # 构建前端并启动 http://localhost:3000
```

开发模式（前后端热更新）：

```bash
node server/index.js      # 终端 A：后端 3000
npm run dev               # 终端 B：前端 5173，自动代理 /api
```

## 环境变量

| Name | Value | 说明 |
| --- | --- | --- |
| `SUPABASE_URL` | `https://你的项目ID.supabase.co` | Supabase Project URL |
| `SUPABASE_ANON_KEY` | `sb_publishable_你的key` | Supabase Publishable key（**不是** sb_secret_ 保密密钥） |
| `NODE_ENV` | `production` | 部署到 Vercel 时使用 |
| `CLIENT_BASE_PATH` | `/` | 前端挂载路径 |

## 数据库

```sql
create table if not exists tasks (
  id bigint generated by default as identity primary key,
  title text not null,
  priority text not null default '中' check (priority in ('高', '中', '低')),
  completed boolean not null default false,
  created_at timestamptz not null default now()
);

alter table tasks enable row level security;
create policy "Allow anon read" on tasks for select using (true);
create policy "Allow anon insert" on tasks for insert with check (true);
create policy "Allow anon update" on tasks for update using (true) with check (true);
create policy "Allow anon delete" on tasks for delete using (true);
```

> 以上策略是「任何人都能读写」，仅供教学演示；正式项目应改为「登录用户只能操作自己的数据」。

## API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/tasks?priority=高` | 查询列表（按创建时间倒序），priority 可省略 |
| POST | `/api/tasks` | 新增，body：`{ "title": "...", "priority": "中" }` |
| PATCH | `/api/tasks` | 切换完成，body：`{ "id": 1, "completed": true }` |
| DELETE | `/api/tasks?id=1` | 删除 |

## 部署到 Vercel

1. 导入本仓库，框架自动识别为 Vite；
2. Environment Variables 添加 `SUPABASE_URL`、`SUPABASE_ANON_KEY`、`NODE_ENV=production`、`CLIENT_BASE_PATH=/`；
3. Deploy，得到 `https://xxx.vercel.app`。
